SMART PORTFOLIO MANAGEMENT SYSTEM
Language Switching (English + Hindi + Punjabi) - Full Working Plan

Goal
- Jab user language change kare (English, Hindi, Punjabi), to poori website ki language change ho.
- Language preference user account ke saath save ho (backend PHP/Laravel).
- Login ke baad bhi selected language same rahe.

Why this is needed
- Abhi language partial hai (kuch pages hardcoded English me hain).
- Current i18n setup me Spanish (es) hai, Punjabi (pa) nahi hai.
- Sirf frontend switch se preference tab/session tak limited reh sakti hai; backend save karne se persistent experience milta hai.

Current status in this project
- Frontend i18n file exists: frontend/src/i18n.js
- Languages currently: en, hi, es
- Backend API exists (Laravel): backend/routes/api.php
- Auth endpoints already available; language preference endpoint add karna easy hai.

D. Add dedicated language endpoint (recommended)
Route (auth protected):

Controller method

E. Return preferred_language in /auth/me
- Ensure AuthController@me response me preferred_language included ho.
- Frontend app boot pe /auth/me call karke i18n sync kare.

==================================================
3) FRONTEND <-> BACKEND INTEGRATION FLOW
==================================================

When user changes language from dropdown:
1. i18n.changeLanguage(code)
2. localStorage.setItem('i18nextLng', code)
3. If logged in, call PUT /api/auth/language with { preferred_language: code }

On app load:
1. If authenticated, fetch /api/auth/me
2. If preferred_language exists, i18n.changeLanguage(preferred_language)
3. Else fallback to localStorage/detection

Why this flow
- Guest users ke liye quick local switch
- Logged-in users ke liye permanent account-level preference
- Device change par bhi language same rahegi

==================================================
7) WHAT WE ARE DOING AND WHY (Simple explanation)
==================================================

Hum 3 cheezein kar rahe hain:
1. Frontend i18n ko 3 required languages (English, Hindi, Punjabi) par standardize kar rahe hain.
2. Sare visible texts ko translation keys par move kar rahe hain, taaki full website language switch ho.
3. PHP/Laravel backend me preferred_language save kar rahe hain, taaki language permanently user account se bind ho.

Isse result milega:
- Language change instant bhi hoga aur persistent bhi.
- User ko har login/device pe same language experience milega.
- App professional aur production-ready multilingual setup ban jayega.
